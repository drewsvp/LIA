# Data directories

Both subdirectories here are intentionally untracked. They contain names, email
addresses, and phone numbers for several hundred members of the public.

## `legacy-export/`

Place the six Wix CMS collection exports here before running `transform.py`.
Export them from the Wix dashboard (Content Manager → each collection → Export
to CSV). Filenames must match exactly:

- `Area_Needs_-_Organizations.csv`
- `Area_Needs_-_Item_Requests.csv`
- `Area_Needs_-_Items.csv`
- `Area_Needs_-_Volunteer_Requests.csv`
- `Area_Needs_-_Volunteer_Roles.csv`
- `Area_Needs_-_Donors.csv`

Wix may deliver files with `+` instead of `_` in the name (for example
`Area+Needs+-+Donors.csv`). Rename on download so the names above match what
`transform.py` expects.

## `load/`

Generated by `transform.py`. Holds the thirteen table CSVs ready for `\copy`
via `load.sql`. Do not commit.
